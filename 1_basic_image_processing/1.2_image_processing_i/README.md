# Sprint 1.2

## Deliverables
* Notes on the Image Processing I subsection of First Principles of Computer Vision (`notes_1.2.pdf`)
* Image Processing Suite code (`linear_filters.py` and `nonlinear_filters.py`)
    - Point Processer: a program to convert edit images based solely on a pixel’s own value rather than the values of pixels around it
    - Linear Image Filterer: a program to apply kernels to images for Gaussian Smoothing and Edge Highlighting
    - Non-Linear Image Filterer: a program to apply a more dynamic filter to images, such as a Median and Bilateral Filter

* Proof of work
    - Image with Gaussian Blur (a linear filter) applied (`gaussian_blur.png`, original on left, filtered on right)
    - Image with Bilateral Filter (a nonlinear filter) applied (`bilateral_filter.png`, original on left, filtered on right)
