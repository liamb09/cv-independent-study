# Sprint 1.1

## Deliverables
* Notes on the Binary Images subsection of First Principles of Computer Vision (`notes_1.1.pdf`)
* Binary Image Processing Suite code (`binary_img_utils.py`)
    - Normal to Binary Image Converter: a program to convert normal images to binary images
    - Binary Image Orientation Identifier: a program to establish a common orientation identifier from object properties
    - Binary Image Segmenter: a program to identify and differentiate separate objects in a binary image (not completely finished)
* Proof of work
    - Converted binary image with center of mass and orientation labeled (`binary_image.png`)
    - Converted binary image with objects segmented, indicated with different colors (`segmented.bmp`)
